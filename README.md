# 💳 ATM Simulation System

A simple **console-based ATM Simulation System** developed in C++. The project simulates basic ATM operations such as PIN authentication, balance checking, deposits, withdrawals, transaction history, and PIN changes.

## 🚀 Features

* 🔐 PIN-based Authentication
* 💰 Check Account Balance
* 💵 Withdraw Money
* 💳 Deposit Money
* 📄 View Transaction History
* 🔄 Change PIN
* ⚠️ Input Validation
* 🔒 Maximum 3 Login Attempts
* 💾 File Handling for Balance and Transactions

## 🛠️ Technologies Used

* **C++**
* **Dev-C++**
* File Handling (`fstream`)
* Functions
* Loops
* Conditional Statements
* Strings

```text

```

The PIN can be changed using the **Change PIN** option.

```text
====================================
           ATM MAIN MENU
====================================
1. Check Balance

5. Change PIN
6. Exit
====================================
```

## 💾 File Handling

The program automatically creates:

* `account.txt` — Stores the current account balance.
* `transactions.txt` — Stores transaction records.

## ▶️ How to Run

1. Download or clone this repository.
2. Open `ATM.cpp` in **Dev-C++**.
3. Compile the program.
4. Run the program.
5. Enter the default PIN `1234`.
6. Select an operation from the ATM menu.
